## 怎么读这份报告

- **完成率**高但**代码通过率**低 = 系统答得漂亮、生成的东西跑不起来。这是最危险的一种"好用"。
- **agent 数恒为 1** = 多 agent 协作没真发生，编排层退化成了单 agent 串行。
- **交接次数为 0** = 只有口头分工，没有实际接力。
- **重试数为 0** = 要么模型一次就对（不太可能），要么错误纠错没被触发（需查熔断阈值）。
