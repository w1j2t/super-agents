# 指标手册（data-agent 领域底座）

用途：指标定义、归因分析、数据质量核查、结论强度判定类任务的判定依据。
铁律：**先定口径，再看数**。口径不清的分析，结论一定站不住，而它长得跟正确的结论一模一样。

---

## 1. 指标定义三要素（metric-card）

任何指标进分析前，先写一张卡。三要素缺一个，这个数就不能进结论。

| 要素 | 要写清什么 | 缺失时的典型后果 |
| --- | --- | --- |
| 定义式 | 分子 / 分母到底是什么 | "转化率"三个人算出三个数 |
| 口径 | 时间窗、去重规则、含不含测试单/内部单 | 同比差额全是口径差 |
| 数据源 | 哪张表 / 哪个事件 / 谁维护 | 换个数仓表，数就变了，无法复核 |

补充四项（易漏但常致命）：
- **统计粒度**：按用户、按会话、按订单？
- **时区**：UTC 还是本地？跨零点行为差异极大。
- **回溯窗口**：7 日 / 30 日归因窗口是否一致？
- **排除项**：机器人、刷单、内部账号、退款单是否剔除？

## 2. 归因维度树（attribution-tree）

自上而下五层，逐层排除。**不要一上来就归因到"活动效果不好"**。

```
1 指标口径层   —— 是不是口径变了？（先排这个，成本最低）
2 数据质量层   —— 是不是埋点丢/重复/延迟？（六查见 §4）
3 规模层       —— 是分母变了还是分子变了？
4 结构层       —— 分群、渠道、端、地域的构成变了吗？（辛普森悖论高发区）
5 行为层       —— 留存/频次/客单/转化路径哪一环掉了？
```

每层都要给出：**假设 + 验证方式 + 数据结论**。没有验证的假设不是归因，是猜测。

## 3. 结论强度规则

| 掌握的证据 | 允许的表述 |
| --- | --- |
| 只有一条时间序列的相关性 | "同期发生，不能推断因果" |
| 有分群对照（A/B 或自然实验） | "在该对照下，X 组比 Y 组高 N 个百分点" |
| 样本量不足（< 30 或置信区间跨 0） | "样本不足以判定，当前差异不显著" |
| 多源交叉验证一致 | "可以认为…（附来源与口径）" |

禁止的表述：把相关说成因果、把单点波动说成趋势、把预估说成实测、把"我没查到"说成"不存在"。

## 4. 数据质量六查（dq-check）

| 查项 | 怎么查 | 判为"有问题"的阈值（参考） |
| --- | --- | --- |
| 缺失 | 关键字段 null 率 | > 5% 需说明 |
| 重复 | 主键/事件 ID 去重前后行数差 | 差 > 1% 需说明 |
| 口径漂移 | 与上期定义逐项对照 | 任一要素变化即视为漂移 |
| 时区 | 跨零点行为分布是否有异常堆积 | 0 点堆积异常升高 |
| 单位 | 金额/时长单位是否一致（分/元、秒/毫秒） | 出现 100 倍或 1000 倍级跳变 |
| 埋点丢失 | 关键步骤漏斗 vs 客户端日志比对 | 漏斗某层断崖式下跌 |

## 5. 常见分析陷阱

1. **辛普森悖论**：整体上升、各分群都下降 —— 必须分群复核。
2. **幸存者偏差**：只统计留下来的用户，得出"体验变好了"。
3. **均值掩盖分布**：平均时长不变，但分布双峰化（一部分极快、一部分极慢）。
4. **窗口滑动**：改动统计窗口后指标自然"变好"，实为口径变化。
5. **分母漂移**：拉新口径放宽，转化率下降其实是分母变大。
6. **过度归因**：把一个系统性变化归给单次活动。

## 6. 输出格式（metric-card + attribution-tree）

1. **口径卡**：指标名、定义式、口径、数据源、粒度、时区、排除项。
2. **现状**：数值 + 对比基线（上期/同期/目标），标明对比口径是否一致。
3. **拆解**：按维度树逐层给出结论，每层写"假设→验证→结论"。
4. **归因**：只写被数据支持的部分，其余列入"待验证假设"。
5. **结论强度标注**：每条结论后标 `强 / 中 / 弱`（依据 §3）。
6. **建议下一步**：需要补什么数据、做什么实验才能把"弱"变"强"。

## 7. 红线

- 不臆造数字。拿不到的数据写"缺"，并说明缺哪张表/哪个埋点。
- 不把预估当实测。必须标注"预估"及其假设。
- 涉及个人明细的数据，输出只给聚合结果，不列明细行。
- 样本量、置信区间、对比组这些前提，**结论里必须写出**，不能让读者自己猜。
