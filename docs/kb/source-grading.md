# 来源分级（research-agent 领域底座）

用途：`source-grading` 与 `evidence-log` 技能的执行判据。分级决定**结论能说多重**。

---

## 1. 五级来源

| 级别 | 类型 | 例 | 可用于 |
| --- | --- | --- | --- |
| A 一手权威 | 原始发布、官方文档、标准原文、监管公告 | 厂商官方文档、法规原文、标准文本 | 直接支撑结论 |
| B 可核查二手 | 有署名、有方法、可追溯的一手引用 | 权威媒体调查、学术论文、官方白皮书 | 支撑结论，注明"据…" |
| C 一般二手 | 常规媒体报道、百科、行业博客 | 门户新闻、维基 | 仅作线索，须回溯到 A/B |
| D 聚合与转述 | 内容农场、摘要站、AI 生成摘要 | 搜索结果摘要、搬运号 | 不得单独作为依据 |
| E 不可用 | 匿名贴、营销软文、无出处截图 | 匿名论坛、广告页 | 不引用 |

## 2. 判定六问（拿到一条来源先过一遍）

1. **谁说的**：有无署名作者/机构，是否有相应资质？
2. **何时说的**：发布日期是否明确？是否已过时（技术/政策类一般 12 个月为界）？
3. **原始在哪**：是转载还是原文？能否点到原始发布？
4. **怎么得出**：有没有方法、样本、口径说明？
5. **有没有利益相关**：厂商自评价、竞品互评要打折。
6. **能否交叉验证**：至少两家独立来源一致？

任意两项答不上来 → 降一级。

## 3. 引用规范

- 每条结论后紧跟来源标记：`[A:官方文档, 2026-09]`。
- 同一事实多个来源时，只引最高级那条，其余列"另见"。
- **数字必须带口径**：统计口径、时间窗、样本量，缺一项就要注明"口径未说明"。
- 直接引语要保真，删节用 `…` 标出，不改写。
- 无法打开的链接（404/需登录）不得作为唯一依据。

## 4. 结论措辞与来源级别的对应

| 最高来源级别 | 允许措辞 |
| --- | --- |
| A | "根据 X 官方文档，……" |
| B | "据 X 报道/论文（可查证），……" |
| C | "有报道称……，尚需向官方核实" |
| D/E | "未能从可靠来源确认……" |

**禁止**：把 C/D 级信息写成确定结论；把"没搜到"写成"不存在"；用记忆补全来源中缺失的数字。

## 5. evidence-log 记录格式

```
[序号] 结论要点
  - 来源：标题 / 发布方 / 日期 / URL
  - 级别：A/B/C
  - 关键原文：…（不超过两行）
  - 口径：统计范围 / 时间窗 / 样本量
  - 冲突：若无写"无"；若有列出对立来源与差异
```

## 6. 红线

- 不臆造 URL、标题、作者、日期。
- 不把摘要当原文；引用前必须读过正文。
- 涉及法律、医疗、金融决策的信息，只能引 A 级并注明"以官方最新发布为准"。
- 检索无果时，明确输出"未找到可靠来源"，并列出已尝试的检索式，让用户判断是否换路。
