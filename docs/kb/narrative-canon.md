# 叙事与世界观检查清单（narrative-canon）

> 用途：`narrative-agent` 的 `doc_refs` 目标文件。
> 这份清单只关心**承重结构**——信息是否交代、动机是否成立、代价是否守恒。
> 文字是否漂亮归 `doc-agent`，数值是否平衡归 `game-agent`。

## 1. 设定自洽三问

新增任何一条设定，先过三问，过不了就别加：

| 问题 | 判据 | 常见敷衍答法 |
| --- | --- | --- |
| 与旧设定是否冲突 | 能点出它推翻了此前哪一条**已公开**的规则 | 「大致不冲突」——没点出具体条款就是没查 |
| 约束了谁的行为 | 至少能让某个角色的选择变少或变难 | 「丰富了世界观」——丰富不是约束 |
| 读者凭什么知道 | 通过哪场戏、哪句对话、哪个物件透露 | 「旁白会解释」——最省事也最廉价 |

**代价守恒**：设定的能力越强，限制必须越硬。只给能力不给限制的设定，
第一次好看，第三次就成了作者按开关。

## 2. 人物动机链四段

四段缺任意一段，人物就会被读者读成「剧情需要」：

| 环节 | 要求 | 反例 |
| --- | --- | --- |
| 想要什么 | 具体到可失败（拿到某物 / 阻止某人 / 守住某处） | 「想变强」——不可失败，等于没有目标 |
| 为什么是现在 | 触发事件是什么 | 「他早就想这么做了」——那为什么现在才动 |
| 愿付什么代价 | 代价决定人物厚度 | 「他毫不犹豫」——无代价的决心不是选择 |
| 失败会失去什么 | 把后果写清，紧张感才有落点 | 「失败了再说」——读者无法预支紧张 |

**反派专项**：反派需要一个**读者能理解但不能认同**的理由。
只写"他坏"是懒；只写"他很惨"是卖惨。两者都不是动机。

## 3. 伏笔四态台账

每条伏笔必须落在四态之一，且**「未埋先收」一律判定为缺陷**：

| 状态 | 含义 | 处置 |
| --- | --- | --- |
| 已埋未收 | 埋设位置明确、回收待定 | 可接受，但必须登记预期回收窗口 |
| 已埋已收 | 两端都明确 | 健康 |
| **未埋先收** | 回收时读者不知道这回事 | 缺陷：要么补埋，要么删掉回收 |
| 埋了不收 | 埋了却永不回收 | 债务：要么回收，要么明确它是氛围而非伏笔 |

## 4. 信息交代顺序（节奏五拍）

读者不是不能接受意外，是不能接受**没有依据**的意外。检查五个节点：

1. **异常**：第一个不对劲的细节出现在哪里
2. **怀疑**：角色第一次明确意识到不对，触发条件是什么
3. **求证**：他做了什么去验证，失败了几次（失败次数决定可信度）
4. **确认**：读者跟着角色一起确认，还是被瞒到最后
5. **代价**：确认之后必须付出点什么，否则前面的紧张是白给的

## 5. 设定漂移高发信号

出现下列句式时，八成是在**事后补设定**，需要回查前文是否已有支撑：

- 「其实……」（其实他早就知道 / 其实那不是他）
- 「原来……」
- 「早就……」
- 「他一直……」
- 「不知为何，他……」（作者自己也没想好）

## 6. 交付要求

产出必须包含：命中的漂移句（摘出所在分句）、伏笔缺口清单、缺失的动机环节（逐条）。
只给「建议加强人物塑造」这类评语，等于没做这份工。
