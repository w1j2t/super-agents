# 市场与竞品分析手册（market-playbook）

> 用途：`market-agent` 的 `doc_refs` 目标文件。
> 本手册只接受**能被当场反驳**的结论。写不出反驳条件的话，一律当废话处理。
> 检索取证与来源分级归 `research-agent`；算账与预算归 `finance-agent`。

## 1. 竞品矩阵五维

| 维度 | 填法 | 空着意味着 |
| --- | --- | --- |
| 目标用户 | 具体到可被找到的人群特征 | 产品还没定 |
| 核心卖点 | 一句话说清"凭什么换过来" | 说不清＝没有卖点 |
| 价格带 | 与竞品的价差，以及价差被什么解释 | 无解释的贵，只会引来"凭什么" |
| 渠道 | 用户第一次在哪见到它 | 获客路径不明，投放就是撒钱 |
| 可替代方案 | 包括"不做"（继续用 Excel、继续忍着） | 漏掉最常见的那一个竞品 |

**最常被漏的竞品是"用户现在凑合用的土办法"。** 它不花钱、不用学、没有迁移成本，
所以你的方案必须先赢过它，才轮到赢过同行。

## 2. 定位三问

1. **为谁**——"年轻人"不算，范围太宽等于没定位
2. **解决什么问题**——用户此刻用什么凑合解决？凑合方案就是真竞品
3. **凭什么相信你**——可验证的证据（数据 / 试用 / 案例），不是形容词

三问有一条答不出，就说明还处在"想做点什么"的阶段，不该进入定价与投放。

## 3. 定价阶梯四层

| 档位 | 真实任务 | 常见误判 |
| --- | --- | --- |
| 入门档 | 把"愿意试"的门槛降到接近零，任务是获客不是赚钱 | 指望入门档赚钱，于是定得不够低 |
| 主力档 | 80% 用户应落在这里 | 主力档卖不动时降价，其实是定位错了 |
| 尊享档 | 让主力档显得划算，并对重度用户收足价值 | 把尊享档当主要收入来源 |
| 档间升级理由 | 功能或额度必须有可见断点 | 只有价格差、没有功能差，用户会选中间的凑合 |

## 4. 渠道四维打分

获客成本 / 与目标用户的匹配度 / 可复现性 / 回本周期。
四项都好的渠道不存在——能说清**牺牲了哪一项**，才算想清楚了。

## 5. 空洞断言黑名单

出现即要求补数字，否则结论不成立：
极具潜力、巨大空间、用户痛点明显、体验至上、性价比高、蓝海、刚需、高频。

## 6. 数字纪律

每个数字必须带**单位**与**时点**：
- ❌「月销 3 万」→ 缺单位（件/元）与时点
- ✅「2026 年 9 月，单月售出 3 万件」

自己算出来的预测必须标注假设来源。没有假设的预测，是把猜测包装成数据。
