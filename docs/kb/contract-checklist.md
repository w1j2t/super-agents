# 合同条款检查清单（legal-agent 领域底座）

用途：合同审阅、条款风险分级、谈判要点、履约争议准备类任务的判定依据。
边界：**本清单用于识别风险与准备问题，不构成法律意见**。重大条款、诉讼策略须由执业律师复核。

---

## 1. 必备条款十一条

| # | 条款 | 缺失风险等级 | 缺失后最容易发生什么 |
| --- | --- | --- | --- |
| 1 | 标的与范围 | 高 | 交付边界不清，验收时互相扯皮 |
| 2 | 价款与支付条件 | 高 | 付了钱拿不到货，或干完活收不到钱 |
| 3 | 交付与验收标准 | 高 | "验收不合格"成为无限期拒付理由 |
| 4 | 履行期限与进度 | 中 | 无明确逾期后果，进度失控 |
| 5 | 违约责任 | 高 | 对方违约无成本，自己违约赔到破产 |
| 6 | 知识产权归属 | 高 | 交付物权属不清，二次使用即侵权 |
| 7 | 保密与数据合规 | 中高 | 数据越界使用、泄露后无法追责 |
| 8 | 变更与解除 | 中 | 需求变更无程序，口头改动引发争议 |
| 9 | 不可抗力 | 低中 | 事件发生时无免责依据 |
| 10 | 争议解决与管辖 | 中 | 被迫异地诉讼，成本吃掉标的额 |
| 11 | 通知与送达 | 低 | 送达地址无效，视为未通知 |

## 2. 高危句式七类（red-flag-scan 判据）

| 类型 | 典型写法 | 风险实质 | 建议改法 |
| --- | --- | --- | --- |
| 单方变更权 | "甲方有权根据业务需要调整…，乙方应予配合" | 范围/价格可被单方改写 | 限定变更范围，且须书面确认并调价 |
| 无限责任 | "乙方承担由此造成的一切损失" | 责任无上限，可能远超合同额 | 设责任上限（如合同总额的 100%） |
| 视为条款 | "乙方未在 3 日内回复视为认可" | 沉默即同意，程序不公 | 改为明确书面确认，或延长至合理期限 |
| 自动续期 | "期满未提出异议自动续约一年" | 遗忘即续，形成长期锁定 | 改为双方书面续签 |
| 排他与竞业 | "合作期内不得与同类第三方合作" | 业务被锁死，无对价 | 限定范围/期限，并约定补偿 |
| 验收主观化 | "以甲方满意为准" | 标准不可证伪 | 改为客观可验证的验收清单 |
| 管辖不利 | "由甲方所在地法院管辖" | 异地诉讼成本高 | 争取被告所在地或仲裁 |

补充高危信号（同样要标）：
- **付款条件与第三方挂钩**："待最终用户付款后支付" → 背靠背风险。
- **知识产权一揽子转让**：含背景技术、通用组件，会波及既有产品。
- **违约金与损失赔偿并行**：可能构成双重追偿。

## 3. 违约与赔偿测算

- 违约金比例市场常见区间：日万分之三 ~ 千分之一；总额上限常见 5%~20% 合同额。
- 判断是否过高：违约金 > 实际损失 30% 通常可主张调减（司法实践口径，非绝对）。
- 双向对等检查：**只约束一方**的违约条款要单独标出来，这是谈判必争项。
- 赔偿范围要区分：直接损失 / 间接损失 / 可得利益。**默认应排除间接损失与可得利益**。

## 4. 知识产权与数据合规

- 交付物权利要拆三层：**所有权、使用权、二次开发权**。只写"归甲方所有"通常不够，还要写乙方能否复用通用组件。
- 背景知识产权（乙方既有技术）必须明确排除在转让之外，否则等于把家底送人。
- 涉及个人信息的，要写清：处理目的、范围、保存期限、跨境传输与否、泄露通知义务。
- 涉及开源组件的，要确认许可证类型（GPL 类具有传染性，会波及整体代码）。

## 5. 谈判底线（negotiation-baseline）

按"可让 / 需换 / 不可让"三档给建议，不要只说"建议修改"。

| 档 | 条款示例 | 说明 |
| --- | --- | --- |
| 可让 | 通知送达方式、文本格式 | 影响小，可换取对方在实质条款让步 |
| 需换 | 付款节点、验收周期、违约金比例 | 可接受，但必须换回等价条件 |
| 不可让 | 无限责任、一揽子 IP 转让、单方解除且不补偿 | 一旦接受，风险与收益严重不对称 |

## 6. 审阅输出格式（clause-audit）

1. **合同画像**：类型、双方、标的额、期限、适用法律。
2. **必备条款对照表**：有/无/不完整，缺失项标风险等级。
3. **高危条款清单**：原文位置（第几条）+ 风险实质 + 一句话改法。
4. **风险分级**：按"会导致直接损失 / 会导致履约困难 / 仅需完善"三档。
5. **谈判要点**：按上表三档给建议，每条附"如果对方不同意，退让到哪"。
6. **待确认清单**：需要业务方或律师补充的信息（如实际交付内容、历史合作背景）。

## 7. 红线

- 不出具法律意见、不预测判决结果、不代替律师。
- 不臆造法条编号与判例。引用法律时只写名称与大致规则，具体条文号须核实后再说，否则标注"待核实"。
- 涉及刑事风险（商业贿赂、串标、侵犯商业秘密）的表述，一律标注"须由专业机构判断"。
