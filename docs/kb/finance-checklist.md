# 财务核算检查清单（finance-agent 领域底座）

用途：报销汇总、发票核对、对账、预算执行、成本归集类任务的判定依据。
铁律：**账上每一个数字都要能追到一张单据**。追不到的一律写"待补"，禁止估算后当结论。

---

## 1. 口径三问（任何金额分析前必须先答）

| 问 | 要确认什么 | 答不上来的后果 |
| --- | --- | --- |
| 期间 | 自然月 / 财年 / 项目期？起止日期是否含截止日？ | 跨期费用重复计入或漏计 |
| 主体 | 哪个法人 / 哪个部门 / 哪个项目？是否含关联方？ | 成本归错主体，考核数据全错 |
| 税 | 含税还是不含税？税率多少？专票还是普票？ | 同比数据混口径，差额全是税 |

补充两问：
- **币种**：本币还是原币？汇率用的是哪天？（跨币种最容易出现"合计对不上"）
- **权责发生时点**：按发票日、按验收日，还是按付款日？（三者在跨月时差别极大）

## 2. 单据链：五单一致

一笔合规支出，五单必须能在**金额、日期、对象、事由**四个维度互相咬合。

```
合同 → 验收单 → 发票 → 付款凭证 → 入账凭证
```

| 环节 | 必查点 |
| --- | --- |
| 合同 | 金额上限、付款条件、是否框架协议 |
| 验收单 | 有签字/系统确认、验收日期在合同期内 |
| 发票 | 抬头与税号、金额与合同一致、开票日期不早于验收 |
| 付款凭证 | 收款账户与合同主体一致（**变更账户是最高危信号**） |
| 入账凭证 | 科目正确、辅助核算项（部门/项目）填全 |

断链处理：
- 缺验收 → 挂"待验收"，不得直接入账。
- 发票金额 > 合同金额 → 挂"超合同"，需补补充协议。
- 收款账户 ≠ 合同主体 → **立刻停付并上报**，不要"先付后补说明"。

## 3. 异常信号六条（anomaly-scan 判据）

1. **重复报销**：同一发票号、同一金额、同一日期，跨批次出现。
2. **金额跳变**：同一供应商同类费用，环比波动 > 30% 且无合同依据。
3. **跨期报销**：费用发生在两个期间以上，集中在期末突击入账。
4. **缺验收先付款**：付款日期早于验收日期。
5. **拆分规避**：连续多笔金额刚好低于审批阈值（如 4900 / 4950）。
6. **账户变更**：收款账户与历史记录不一致，尤其伴随"加急"话术。

每条命中都要给出：**命中证据（单号/金额/日期）+ 建议动作（退回补件/上级复核/停付）**。

## 4. 汇总维度（按需求选，别一股脑全上）

| 维度 | 适用问题 | 常见陷阱 |
| --- | --- | --- |
| 费用科目 | 钱花在哪类事上 | 科目混用（差旅塞进办公费） |
| 部门/项目 | 谁花的 | 共同费用未分摊，全压给一个部门 |
| 供应商 | 依赖谁 | 同一供应商多个抬头，实际未合并统计 |
| 期间 | 什么时候花的 | 跨期单未按权责发生制调整 |
| 审批人 | 谁批的 | 自批自报未识别 |

## 5. 预算与成本归集

- 预算执行率 = 已发生 / 预算。**已发生**要说明含不含在途（已批未付、已签未验收）。
- 偏差分析必须分两层：**量差**（做多了/做少了）与**价差**（单价变了）。只报总偏差等于没分析。
- 共同成本分摊要有依据（人头、面积、工时），且分摊规则一经确定不得中途更换。

## 6. 交付格式（voucher-chain-check 输出）

1. **口径卡**：期间 / 主体 / 含税口径 / 币种与汇率日。（缺任何一项，结论标注"口径待确认"）
2. **汇总表**：金额、笔数、占比，按选定维度排序。
3. **断链清单**：缺哪一单、缺什么字段、建议动作。
4. **异常清单**：命中哪条信号、证据是什么。
5. **待补输入**：需要用户提供但当前拿不到的材料（列清文件名与用途）。

## 7. 红线

- 不估算、不推测、不"先按 10% 估"。**无法确认的数字写"待补"**，并说明补什么才能算。
- 不做税务筹划建议、不出具审计意见。涉及申报口径与法律定性的，标注"需财务负责人/税务顾问复核"。
- 涉及个人薪资、身份证号、银行账号等敏感字段，汇总时脱敏（只留末四位），不在结论里复述完整号码。
