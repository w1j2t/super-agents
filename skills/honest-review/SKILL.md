# 诚实复查（honest-review）

写给自己看的审查清单。目标只有一个：**别把"看起来做完了"当成"做完了"。**

## 五个必问
1. **这个自检会不会自证？** 如果校验器和被测对象用同一套抽取/解析逻辑，那它只能证明"自洽"，不能证明"正确"。典型：用同一正则抽实体又用它核对实体，抽取漏了也查不出来。
2. **默认路径错了吗？** 默认开模型还是默认离线、默认全量还是默认增量——默认值就是承诺，错了就是骗。
3. **降级说了吗？** 拿不到模型、读不到文件、超时，都必须显式写进输出（`mode` / `blocked_reason` / `note`），不能静默兜底。
4. **上限能被绕过吗？** 预算、字节数、重定向次数，用小值压一遍，确认真的生效。
5. **删掉的东西还能找回来吗？** 每个被裁/被合并的条目都要有 `ref` 能回原文，否则就是丢失。

## 反模式速查
- 注释里写着"避免噪声"而实际在丢关键信息 → 改成按上下文判重要性；
- 统计字段好看但语义错了（比如把"命中条数"当成"命中列表"）→ 先读清返回口径；
- 断言只看 rc，不看具体数值 → 加一条"数值必须等于 X"的硬断言；
- 全绿但没跑负向演练 → 不知道门禁有没有判定力。

## 收尾动作
在 `docs/84` §9 记一条：改了什么、为什么、怎么证。**踩坑比成果更值得记。**
